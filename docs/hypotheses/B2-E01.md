## 1. Problem (identical for every arm; frozen Batch-1 benchmark FE-D-M1)

    c² u_xxxx + u_tt + γ u_t = 0,  (x,t) ∈ [0, L] × [0, T],  L = 2.75 m, T = 1 s,
    c² = 43.73² = 1912.3129 m⁴/s²,  γ = 7.08 1/s                                  (paper Eq. 49)
    BC (fixed–fixed):  u = u_x = 0 at x = 0 and x = L
    IC:                u(x,0) = u₀(x) = A0 φ₁(x)/φ₁(L/2),  u_t(x,0) = 0,  A0 = 0.08 m

φ₁ is the fixed–fixed mode-1 shape with the exact root β₁L = 4.730040745. The IC is part of the problem
statement (Batch-1 `ic_shape: exact`).

ω₁ = β₁²c = 129.373 rad/s is computed from the PDE coefficient and the BC eigenproblem only. It enters the
tanh² time factor, which is a declared Batch-1 prior.

**No arm uses the exact reference solution u(x,t) during training.** The references are used only for
evaluation.

## 3. Mixed formulation — derivation and checks (arm 2)

**Auxiliary variable.** Let v := u_xx, the curvature. Bending moment M = −EI v; v has units of 1/m.

**Coupled system.** Substituting u_xxxx = v_xx:

    (S1)  v − u_xx = 0
    (S2)  c² v_xx + u_tt + γ u_t = 0

**Dimensional check:**
- c² v_xx has units [m⁴/s²]·[1/m³] = m/s², the same as u_tt and γu_t. ✓
- The scaled link residual r_link = c²β₁²(v − u_xx) has units [m⁴/s²]·[1/m²]·[1/m] = m/s², the same as
  r_pde. ✓

For a modal field both residuals have characteristic size c²β₁⁴A0 = ω₁²A0 ≈ 1339 m/s². The scaling is
dimensional and declared, not tuned. The two loss terms have weight 1 each:

    L = ½·mean(r_link²) + ½·mean(r_pde²)

**Equivalence.** For smooth fields:
- if (u, v) solves (S1)–(S2), then u_xxxx = (u_xx)_xx = v_xx, so u solves the original PDE;
- conversely, a solution u gives v = u_xx.

The solution set for u is therefore identical. In code, if v := u_xx exactly then r_pde equals the strong
residual for any network (`tests/test_b2_formulations.py::test_mixed_equals_strong_when_link_is_satisfied`).

**Boundary conditions.** The physical BCs are imposed on u **exactly**, by the same hard ansatz as B1:

    u = u₀(x) + g(t) Φ(x) A0 N_u,   Φ = 16x²(L−x)²/L⁴

Φ has double roots at x = 0 and x = L, so u = u_x = 0 there for any N_u; u₀ satisfies the BCs.

**v carries no boundary condition.** At a clamped end the moment is nonzero (for mode 1,
v(0,t) = u₀''(0)q(t) ≠ 0). Imposing v = 0 there would change the problem. No other condition is added.

**Initial conditions:**
- u(x,0) = u₀ and u_t(x,0) = 0 hold exactly (g(0) = g'(0) = 0).
- v(x,0) = u₀''(x) is imposed by v = u₀'' + g(t)β₁²A0 N_v. This is **implied** by S1 and the IC on u, so it
  is consistent and introduces no new information beyond the IC.
- No condition is imposed on v_t(x,0). It is implied by S1, because u_t(x,0) = 0 gives v_t(x,0) = 0, but
  this is not enforced.

**Highest derivative orders:** u_xx, v_xx, u_tt, i.e. 2 in x and 2 in t, versus 4 in x for B1.

**Capacity:** same trunk and encodings as B1; only the head gains 401 parameters.

## 4. Modal diagnostic — derivation (arm 3; DIAGNOSTIC ONLY)

**Galerkin step.** Substitute u = A0 φ̂₁(x) q(t) and use φ₁'''' = β₁⁴ φ₁ (exact eigenfunction):

    A0 φ̂₁ (c²β₁⁴ q + q'' + γ q') = 0  ⇒  q'' + γ q' + ω₁² q = 0,  ω₁² = c²β₁⁴ = 16,737.4 s⁻²
    q(0) = ⟨u₀, φ̂₁⟩/(A0⟨φ̂₁, φ̂₁⟩) = 1,  q'(0) = 0

The Galerkin quadrature check agrees with c²β₁⁴ to < 1e-6 relative; see B2-DIAG-001.

**Ansatz.** q_θ(t) = 1 + tanh²(ω₁t) N_θ(t), so the IC holds exactly. N_θ is the learned network.
**The temporal solution is not hard-coded**; only the ODE residual q'' + γq' + ω₁²q is trained.

**Units.** The loss uses A0·(ODE residual) [m/s²]. This equals the strong residual of the field divided by
φ̂₁(x) (tested identity).

**Caveat (stated in every output).** For FE-D-M1 the one-mode ansatz contains the exact solution and BC/IC
hold by construction. The arm measures **how difficult the temporal dynamics are once the spatial field is
removed**. It is not a competing solver and no PINN-superiority claim is drawn from it. Its wall-clock is
reported but is **not** used in the efficiency comparison (Q1/Q4).

## 5. Compute matching and accounting

Every arm takes exactly 5,000 steps × 128 = **640,000 collocation points**. Actual counts come from the run
records, never nominal values.

Recorded per arm:

| Group | Quantities |
|---|---|
| work | optimizer steps; PDE (collocation) evaluations; residual-vector evaluations (mixed 2 per point, others 1) |
| passes | forward passes (one batched residual-graph forward per step); backward passes (one per step) |

| time and memory | `train_seconds` (training work only); peak RSS (training); peak VRAM (CPU only: 0) |
| model | parameters; model size (bytes) |

**Execution.** The 4 arms run **concurrently**, one process and one thread each, on the 4-vCPU Xeon @ 2.8 GHz.
This is declared. Batch 1 measured no per-step slowdown at 4 concurrent single-thread runs. The FP64 arm
continues alone after the others finish; the per-step time is reported from the logged history.

## 6. Measurements (identical procedure for every arm)

**Final model:**
- the Batch-1 `evaluate_full`: L2_exact/L2_paper on 201×2001; RMSE; late-window L2; PDE residual (strong
  residual of the displacement u, 51×501); IC and BC errors; damped-cosine fit at mid-span (ω, decay,
  amplitude, phase errors vs both references); inference latency;
- the **frozen persistence metric** (displacement and velocity collapse time / cycles);
- amplitude ratio and max|u_t| ratio.

**Mixed only:** RMS of r_link relative to the RMS of the exact u_xx, on the 51×501 grid.

**Snapshots every 1,000 steps** (128,000 evaluations apart): L2_exact, L2_paper and persistence. These give
L2 vs PDE evaluations and the collapse-front curve.

**Training history:** loss vs evaluations, `train_seconds` vs evaluations.

## 7. Decision thresholds (fixed now)

Notation, all measured at matched E = 640,000:
- P, P_v: displacement and velocity persistence (cycles; the full window is 20.58);
- L2e: L2_exact;
- W: `train_seconds`.

All comparisons use the **B1 re-run** from this experiment, not Batch-1 numbers.

**Single-seed noise basis.** Batch-1 seeds 1234 vs 1235 on the Y1 recipe at 5k steps differed by 0.1 cycles
in P and 3 % in L2 (Y1 vs Z2). Thresholds of **1.0 cycle** and **25 %** are therefore ≥ 8× that observed
spread. Stage-1 conclusions are still labelled **provisional (single seed)**.

### 7.0 Reproducibility gate (B1 re-run vs Batch-1 Z4 @ 5k)

Batch-1 values (`references/batch1/tables/phaseZ4_20K_checkpoints.csv`, 5k row):
- L2e 0.52639
- P 3.154 cycles (collapse at 0.153 s)
- P_v 3.360
- R_pde 0.1102
- ω_fit 128.08 rad/s
- decay 8.98 1/s

**PASS** if the run key is identical, |L2e − 0.52639|/0.52639 ≤ 5 % and |P − 3.154| ≤ 0.5 cycles.

**FAIL → STOP**: report the environment/determinism discrepancy before interpreting arms 1b–3.

### 7.1 Accuracy class of an arm X relative to B1 (dynamics first)

| Class | Condition |
|---|---|
| **FULL-WINDOW** | P_X = 20.58 **and** P_v,X = 20.58 (no collapse) |
| **BETTER** | P_X ≥ P_B1 + 1.0 **and** L2e_X ≤ L2e_B1 |
| **COMPARABLE** | \|P_X − P_B1\| < 1.0 **and** L2e_X ≤ 1.25·L2e_B1 |
| **WORSE** | P_X ≤ P_B1 − 1.0, **or** (\|P_X − P_B1\| < 1.0 **and** L2e_X > 1.25·L2e_B1) |
| **TRADE-OFF** | P and L2e disagree (e.g. P_X ≥ P_B1 + 1.0 but L2e_X > L2e_B1, or L2e lower but P lower). Reported, **never called better** |

**Dynamics-correctness diagnostics** (reported for every arm; they block a "better" label if violated):
- frequency error |ω_fit/ω_d − 1| ≤ 2 %;
- amplitude ratio within [0.5, 2];
- max|u_t| ratio within [0.5, 2];
- fitted decay rate reported against the exact 3.54 1/s;
- phase error reported.

A lower L2 with a frequency error > 2 % or an amplitude/velocity ratio outside [0.5, 2] is **not** better.

### 7.2 Compute

"Materially lower compute" means **W_X ≤ 0.75·W_B1** at matched E. Peak RSS and inference latency are
reported alongside.

### 7.3 Cases (PI decision tree, quantified)

| Case | Arm | Condition | Action (pre-registered) |
|---|---|---|---|
| **A** | mixed | class ∈ {FULL-WINDOW, BETTER, COMPARABLE} **and** W_mixed ≤ 0.75·W_B1 | keep as a strong candidate (not novel); recommend a seed-robustness test and the next single controlled combination |
| **B** | mixed | W_mixed ≤ 0.75·W_B1 **and** class ∈ {WORSE, TRADE-OFF} | quantify the Pareto trade-off (L2e and P vs W); do not reject automatically; the wall-clock-matched follow-up is recommended (E' = E·W_B1/W_mixed) |
| — | mixed | W_mixed > 0.75·W_B1 | report "no material compute gain" together with the accuracy class |
| **C** | modal | P_modal ≥ 2·P_B1 (or FULL-WINDOW) **and** L2e_modal ≤ 0.5·L2e_B1 | spatial-field learning is a major source of difficulty; guide formulation-selection research |
| H2-support | modal | P_modal ≤ 1.5·P_B1 | temporal propagation alone reproduces the difficulty after the spatial field is removed |
| partial | modal | neither of the above | report the ratio; stage-2 seeds recommended before concluding |
| **D** | FP64 | \|P_fp64 − P_B1\| ≥ 1.0 **or** \|L2e_fp64/L2e_B1 − 1\| ≥ 25 % **or** a qualitative change (oscillatory ↔ static, or frequency error crossing 10 %) | precision becomes a required branch; previous failures are not attributed solely to optimisation. **Dramatic** if P_fp64 ≥ 2·P_B1 or FULL-WINDOW: reported as a separate mechanism |
| **E** | all | mixed, modal and FP64 each within \|ΔP\| < 1.0 **and** \|ΔL2e\|/L2e_B1 < 25 % of B1, and none FULL-WINDOW | **STOP**: the bottleneck is elsewhere; no new architecture or optimizer complexity |

Cases A/B, C (or H2-support) and D are evaluated independently and can co-occur. E is exclusive.

**Q4 interpretation.** The mixed arm is a mathematically equivalent reformulation. If B1 is dominated on
the (L2e, W) or (P, W) plane — or (FP64) on the precision axis — "yes, a better accuracy/compute point
exists". The modal arm is excluded from Q4 because it solves a reduced problem.
