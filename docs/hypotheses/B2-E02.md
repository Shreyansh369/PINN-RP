# B2-E02 — PRE-REGISTRATION: temporal-optimisation screen in the modal laboratory

**Written before any B2-E02 training.** This file is frozen once the first B2-E02 run starts; its commit
precedes every B2-E02 run record. Later changes are appended as dated amendments with reasons, and nothing
above them is edited.

**Nature:** a mechanistic optimisation screen on a **diagnostic** problem. Nothing tested here is novel:
- Adam with learning-rate decay: Kingma & Ba 2015, plus the reference-code schedule.
- Adam→L-BFGS two-stage optimisation: Rathore et al., ICML 2024; Kiyani et al.
- Causal loss weighting: Wang, Sankaran & Perdikaris, CMAME 2024.
- Modal reduction: classical; RO-PINN 2026.

A possible future contribution is a **problem-adaptive selection/control framework**. That is not claimed
here and will not be claimed without evidence plus a literature audit.

## 0. Evidence this design rests on

The Phase-A numbers are filled in from `results_batch2/tables/B2-E01S_*` and
`results_batch2/reports/B2-E01_SEED_REPLICATION.md`. See §9; that section is written before this file is

## 1. Problem and frozen control (M0)

The modal diagnostic of B2-E01 is used **unchanged**:

    u(x,t) = A0 φ̂₁(x) q_θ(t),   q_θ(t) = 1 + tanh²(ω₁t)·N_θ(t)

- φ̂₁ is the exact fixed–fixed mode-1 shape. It is supplied, and this is why the problem is diagnostic only.
- q_θ is learned. The exact temporal solution is **never** supplied to the network.
- The loss is the ODE residual A0·(q'' + γq' + ω₁²q), with ω₁² = c²β₁⁴ (Galerkin).

**M0** = `physref.arms.ArmTrainer(arm="modal")`, unchanged since B2-E01 commit `24813bf`:
- `TemporalFourierNet`: 6×200 tanh, σ_t = (10, 1), m = 100; B1's temporal Fourier draws and trunk/head
  initialisation; 241,601 parameters;
- Batch-1 sampler (640 points per epoch, mini-batch 128);
- Adam, lr = 1e-3·0.9^(step/1000);
- float32, one thread;
- 5,000 steps = **640,000 PDE evaluations**.

**Frozen-control check (STOP condition 6).** The M0 runs in B2-E02 must reproduce the Phase-A modal runs of
the same seed bit-exactly: L2_exact, persistence and fitted decay equal to 1e-9. This is asserted in
`scripts/analyze_b2_e02.py`. **If it fails, STOP.**

## 2. Observed failure being targeted (from B2-E01 + Phase A)

1. Front-like amplitude collapse. The frequency is correct before the collapse; the amplitude is lost after
   it. (Seed-1234 modal: collapse at 0.370 s, 7.62 of 20.58 cycles.)
2. Systematic over-damping: fitted decay 5.40 1/s vs the exact 3.54.
3. Late-training non-monotonicity and a noisy mini-batch loss. For example, the seed-1234 modal run goes from
   P 8.16 → 7.62 and L2 0.243 → 0.270 between 512k and 640k evaluations.
4. **Not** a precision artefact: FP64 follows the FP32 trajectory (B2-E01, Phase A).

## 3. Hypotheses (falsifiable)

**H-E02 (primary).** The remaining temporal collapse in the modal diagnostic is at least partly an
optimisation / training-control failure. An appropriate optimizer or controller, with no change to network
size, representation, physics or sampling distribution, extends accurate oscillatory propagation and
reduces physical error at matched PDE evaluations.

The two candidates encode two **different** mechanistic sub-hypotheses:

| Arm | Sub-hypothesis | Mechanism | Prediction if true |
|---|---|---|---|
| **LBFGS** (Adam → L-BFGS) | H-E02a: the collapse persists because first-order stochastic optimisation (mini-batch noise, decayed lr) cannot resolve the ill-conditioned late-time residual | deterministic curvature-aware refinement on a fixed point set (Rathore et al. 2024: Adam+L-BFGS beats either alone on ill-conditioned PINN losses) | lower L2 and decay error, front pushed later, no late regression |
| **CAUSAL** (Adam + causal weights) | H-E02b: late-time residuals are driven toward a low-amplitude (over-damped) solution before the early dynamics are resolved, i.e. a violation of temporal causality during training | w_i = exp(−ε Σ_{k<i} L_k) postpones late bins until earlier bins are resolved (Wang et al. 2024) | decay error reduced, front pushed later, possibly slower early progress |

**Falsification of H-E02.** Neither candidate meets the accuracy-improvement criterion (§8.1) in all three
seeds.

## 4. Candidate selection (justified before training; deliberately small)

| Considered | Decision | Reason |
|---|---|---|
| Adam + decay | **control M0** | frozen B2-E01 control (already contains the established schedule) |
| Adam → L-BFGS | **arm LBFGS** | most established remedy for ill-conditioned PINN losses (A2); cost-compatible on CPU |
| causal weighting | **arm CAUSAL** | the one adaptive control mechanism aimed directly at temporal propagation (B6) |
| plain Adam (no decay) | not run | Batch-1 Y phase already showed the schedule helps; it would test a worse controller |
| SOAP, NNCG, KFAC, ENGD | not run | gradient-conflict/Gauss–Newton machinery not native to torch. SOAP's main benefit (A4: inter-term conflict) is absent with a single loss term. ENGD/KFAC need substantial new code. Revisit only if H-E02a is supported |
| MultiAdam, NTK, LRA, GradNorm, ReLoBRaLo, ConFIG | not run | they balance **multiple** loss terms; the modal loss has one term |
| FP64 | not run | shown not material (B2-E01 + Phase A) |
| RAD | not run | negative in Batch 1 |
| R3, temporal decomposition, SIREN, SPINN | not run | excluded by the PI for this phase |
| larger network | not run | excluded: the question is optimisation at fixed capacity |

**Note on causal weighting (honesty).** The legacy Batch-1 notebook rejected a causal-weighting
*combination* with Fourier+NTK (soft constraints, 2×2 ablation with antagonistic interaction; legacy
`REPORT.md` §5.3). It was never tested with exact (hard) IC/BC or on an isolated temporal problem. It is
included **once**, pre-registered, as the single adaptive controller. If it fails here it stays rejected.
No variant search over ε, the number of bins or schedules is permitted.

## 5. Arm specifications (one change each vs M0; identical seed → identical initial weights, tested)

**LBFGS** (`physref.modal_lab.AdamLBFGSModalTrainer`):

*Stage 1.*
- The M0 Adam loop, unchanged, for 2,500 steps = **320,000 PDE evaluations** (a 50/50 split, declared
  a priori, not tuned).
- Stage 1 is bitwise identical to M0's first 2,500 steps (tested).
- Transition point logged: `switch_step`, `switch_pde_evaluations`.

*Stage 2.*
- `torch.optim.LBFGS(lr=1, history_size=50, line_search_fn="strong_wolfe")` with **PyTorch default
  tolerances** (tolerance_grad 1e-7, tolerance_change 1e-9); float32 (the control precision).
- Full-batch on a **fixed** set of 640 collocation times: the next epoch draw of the frozen sampler RNG.

*Accounting.*
- Every closure evaluation, **including line-search evaluations**, counts 640 PDE evaluations, 1 forward
  pass and 1 backward pass.
- Stage-2 budget = (640,000 − 320,000)/640 = 500 closure evaluations.
- Each `LBFGS.step` call receives `max_eval ≤ remaining − max_ls − 1`, so the 640,000 budget is **never
  exceeded**. Unused evaluations are reported; early termination by tolerance is reported as an outcome.
  Termination is the FP32 premature-convergence mechanism of Xu et al. 2025.

*Risks declared.*
- Overfitting to the 640 fixed points (Andersen & Matsubara 2026). This is detected on the dense
  4001-point trace and the 201×2001 grid, never on the training points.

**CAUSAL** (`physref.modal_lab.CausalModalTrainer`):
- M0 with its loss replaced by the causal loss: N_t = 16 equal time bins on [0,1] s, per-bin
  L_k = ½·mean(r²) over the mini-batch points falling in the bin, weights w_k = exp(−ε·Σ_{j<k} L_j)
  (stop-gradient), loss = mean over non-empty bins of w_k L_k.
- **ε fixed by a physics rule, no tuning.** A bin is "resolved" when its residual RMS is 1 % of the
  characteristic scale ω₁²A0. Then L_tol = ½(0.01·ω₁²A0)² = 89.6 and ε = 1/(N_t·L_tol) = 6.97e-4.
- The sampler is unchanged (uniform), so the mini-batch puts ≈ 8 points per bin.
- Accounting is identical to M0: 128 points per step, 640,000 total.
- w_min and w_last_bin are logged.

## 6. Measurements

### 6.1 Every snapshot and the final model

Snapshots fall every 128,000 PDE evaluations: every 1,000 Adam steps; in the L-BFGS stage, the first
closure at or after each 128,000 multiple, with the actual count recorded. Snapshot cadence is metadata and
never defines the budget.

Recorded at each snapshot and for the final model:
- L2_exact and L2_paper (201×2001);
- persistence (displacement and velocity), using the frozen Batch-1 metric, and collapse time;
- fitted ω and frequency error;
- fitted decay rate and |decay − 3.54|;
- phase error and amplitude error;
- **strong PDE residual of the physical displacement u** (51×501, Batch-1 `physics_metrics`);
- amplitude ratio and max|u_t| ratio;
- cumulative PDE evaluations, wall-clock and forward passes.

Final model only:
- IC and BC errors;
- parameters;
- peak RAM;
- optimizer steps;
- L-BFGS closure evaluations and stop reason.

### 6.2 Collapse-front metrics (defined now)

| Metric | Definition |
|---|---|
| t_c, P | collapse time and persistence of the final model (frozen Batch-1 definition) |
| **CF_AUC** | mean collapse time over the evaluated points (all snapshots **plus the final model**, deduplicated by PDE-evaluation count), in seconds (T = 1). This summarises how early the front advances, not only where it ends |
| **CF_regressions** | number of consecutive-snapshot intervals in which t_c *decreases* by more than one damped period (0.0486 s) |
| **E_reach** / **W_reach** | PDE evaluations / wall-clock at the first evaluated point (snapshots + final) whose L2_exact ≤ the control's final L2_exact **and** whose P ≥ the control's final P (same seed) |

## 7. q(t) error decomposition (best candidate and M0, all seeds)

q_θ(t) = u(L/2, t)/A0 is compared with the exact q on 4001 points. The global damped-cosine fit
(Batch-1 extractor) gives (a, λ, ω, φ).

**One-parameter sensitivity terms.** These are relative L2 norms of the exact damped cosine with **one**
parameter replaced by its fitted value:
- `err_frequency`
- `err_decay`
- `err_phase`
- `err_amplitude`

**Remainder.** `err_non_damped_cosine` = relative L2 of q − (fitted damped cosine). This is the part no
damped cosine can explain: the collapse distortion.

**Pre-collapse local diagnostics** (t < t_c):
- median local half-period frequency error from zero crossings;
- phase drift at the last matched zero crossing;
- envelope error mean|R − 1|;
- local log-envelope decay rate.

**7.3 What does the candidate fix?** Compare seed means against M0:

| Category | Rule |
|---|---|
| **A, phase/frequency** | the reduction of err_frequency + err_phase is ≥ 25 % and larger than the reduction of err_decay + err_amplitude |
| **B, amplitude decay** | the reduction of err_decay + err_amplitude is ≥ 25 % and is the larger of the two |
| **C, optimisation stability** | neither reduction reaches 25 %, but the seed standard deviation of P falls to ≤ 50 % of M0's, **or** the total CF_regressions decreases |
| **D, none** | otherwise |

## 8. Decision rules (computed in `scripts/analyze_b2_e02.py`)

All comparisons are per seed, against the M0 run of **the same seed, run in the same concurrent batch**.
This gives identical initial weights and identical machine conditions.

The threshold **ΔP_thr = max(1.0 cycle, 2 × the Phase-A range of modal P over seeds 1234–1236)**. Phase A
supplies the noise floor of the control itself (§9).

### 8.1 Accuracy improvement, per seed: all of

- P_x ≥ P_M0 + ΔP_thr;
- L2_x ≤ 0.9·L2_M0;
- |frequency error_x| ≤ 2 %;
- |decay_x − 3.54| ≤ |decay_M0 − 3.54|;
- PDE residual of u ≤ 1.1 × M0's.

### 8.2 Efficiency improvement, per seed

E_reach ≤ 0.75 × 640,000, **or** W_reach ≤ 0.75 × W_M0.

### 8.3 Dominance, per seed

The accuracy improvement holds **and** W_x ≤ W_M0 at the full budget.

### 8.4 Worse, per seed

P_x ≤ P_M0 − ΔP_thr, **or** L2_x > 1.1·L2_M0.

### 8.5 Candidate label (no pooling across seeds)

| Label | Condition |
|---|---|
| DOMINANCE | dominance in 3/3 seeds |
| ACCURACY+EFFICIENCY | accuracy and efficiency in 3/3 seeds |
| ACCURACY-ONLY | accuracy in 3/3 seeds, efficiency in < 3 |
| EFFICIENCY-ONLY | efficiency in 3/3 seeds, accuracy in < 3. **A cheaper but less accurate run is never labelled "better"** |
| TRADE-OFF / UNSTABLE | some improvement in some seed **and** "worse" in some seed |
| PARTIAL (2/3) | improvement in exactly 2 of 3 seeds |
| NO IMPROVEMENT | otherwise |

**Transfer gate.** Only labels DOMINANCE, ACCURACY+EFFICIENCY, ACCURACY-ONLY or EFFICIENCY-ONLY proceed to
the full-field test (§10).

## 9. Phase-A evidence (seed replication of B2-E01)

Source: `results_batch2/reports/B2-E01_SEED_REPLICATION.md` and `tables/B2-E01S_*`.

**Modal control M0, Phase A:**

| Seed | P [cycles] | L2 | decay [1/s] | t_c [s] |
|---|---|---|---|---|
| 1234 | 7.62 | 0.270 | 5.40 | 0.370 |
| 1235 | 6.62 | 0.304 | 5.89 | 0.322 |
| 1236 | 6.09 | 0.329 | 6.05 | 0.296 |

The P range is 1.53 cycles.

**Thresholds derived from the formulas fixed in §8 and §10** (the formulas were committed in the draft
`450f7dd` before the Phase-A numbers existed):
- **ΔP_thr (modal) = max(1.0, 2 × 1.53) = 3.06 cycles.**
- B1 Phase-A P values are 3.15, 3.11, 5.10 (range 1.99), so **ΔP_thr (transfer) = max(1.0, 2 × 1.99) =
  3.98 cycles**.

**The failure targeted, measured.** In all three seeds the modal front reaches its best state at 384k–512k
evaluations (P 8.16–8.62, L2 0.229–0.243) and then **retreats** by 640k: Δt_c = −0.026, −0.096, −0.123 s.
The full-field fronts are still advancing at 640k.

This late-training regression is the concrete phenomenon that H-E02a and H-E02b must change. The LBFGS
switch at 320,000 evaluations was declared in the draft before these snapshots were analysed. It is not
tuned to the observed peak (384k–512k).

**Wall-clock.** Absolute times vary ≈ 1.3× between sessions, so only same-batch ratios are compared. This is
why M0 is re-run inside every B2-E02 batch.

**Approved training IDs** (PI instruction of 2026-10-07: train only after this file is committed, pushed and
verified): `B2-E02-{M0,LBFGS,CAUSAL}-s{1234,1235,1236}`.

Conditional transfer IDs (§10) are **not** approved by this file. They are added only if a candidate passes

## 10. Full-field transfer test (conditional; same accounting)

**Runs only for candidates that pass the transfer gate.**

| Item | Specification |
|---|---|
| Arms | B1 (frozen, re-run in the same batch) vs B1 + the candidate controller |
| Seeds | 1234–1236 |
| Budget | 640,000 PDE evaluations; L-BFGS switch at 320,000; same fixed-set size of 640 collocation points (x,t) drawn by the frozen sampler |
| Causal ε | same physics rule (residual scale ω₁²A0 is identical for the full field) |
| Implementation | a subclass of the Batch-1 trainer that changes only the controller; tested and committed before launch |

**Transfer success**, all 3 seeds:
- P ≥ P_B1 + max(1.0, 2 × the Phase-A B1 seed range);
- L2 ≤ 0.9·L2_B1;
- frequency error ≤ 2 %;
- PDE residual of u ≤ 1.1 × B1's;
- compute reported.

## 12. Execution policy

- 9 modal runs: 3 arms × 3 seeds.
- One batch per seed: M0, LBFGS and CAUSAL run **concurrently**, one process and one thread each, on the
  same machine. Wall-clock comparisons are within a batch.
- Before every launch, verify: git clean at the recorded commit; output paths under `results_batch2/`;
  ROOT unchanged; experiment IDs approved.

## 13. STOP conditions (PI)

1. Seed replication strongly contradicts B2-E01.
2. An arm cannot be made compute-comparable.
3. The frozen control changes. The M0 bit-exactness check fails.
4. An unreported architectural change.
5. An apparent improvement is traceable to initialisation, hardware, precision or accounting.
6. The modal control changes unexpectedly.

A falsified hypothesis is reported as falsified.
